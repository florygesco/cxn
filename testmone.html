Méthode fiable Ouvrir un onglet en arrière-plan

L'onglet s'ouvre au moment du clic (le navigateur l'autorise), puis on lui redonne le focus sur votre page.

🔗 Tester votre propre URL

Entrez une URL et cliquez : elle s'ouvrira en arrière-plan.

Comparaison Ouverture classique (déplace souvent)

window.open(url) — le navigateur vous déplace très souvent.

En attente Cliquez sur un bouton pour tester.
ℹ️ Comment ça marche :
window.open() doit être appelé directement dans le gestionnaire de clic (pas dans un setTimeout) sinon le navigateur bloque la popup.
Ensuite, on utilise w.blur() pour retirer le focus du nouvel onglet, puis window.focus() pour revenir ici. Sur Chrome / Edge / Firefox desktop, ça marche.
Sur mobile, c'est le navigateur qui décide — aucune méthode ne garantit l'arrière-plan.

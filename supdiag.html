Rôles des équipes

Support
  • Teste tous les espaces chaque jour
  • Reçoit les rapports Diagnostic
  • Analyse les anomalies
  • Met à jour le SIG
  • Alerte l'Équipe Technique
  • Suit les interventions
  • Effectue les tests de validation
  • Assure la clôture du suivi
Diagnostic
  • Effectue les descentes terrain
  • Contrôle les établissements
  • Identifie les anomalies
  • Alerte le Support
  • Transmet un rapport après chaque descente
  • Peut effectuer un recontrôle après intervention
